# DocScout
**Документация к разработке поисковика для офисных документов**

## Описание
Проект включает создание системы для индексации содержимого офисных документов (DOC, DOCX, XLS, XLSX, PDF) 
и архивов (ZIP, RAR, 7Z) с последующим полнотекстовым поиском.

---
Функционал:

* Рекурсивный обход директории.
* Распаковка архивов.
* Извлечение текста из файлов.
* Сохранение данных в CSV.

## Как запустить
```bash
python crawler.py -i ./storage -o results.csv
```
